# HealthCare+ — Responsive Healthcare Portal

A modern, portfolio-ready healthcare portal built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Responsive/mobile-first behavior
- CSS animations and scroll reveal
- Appointment booking demo
- Patient login modal
- Doctor cards and departments
- Health & wellness articles
- Generated healthcare visual asset

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For the best VS Code experience, install Live Server and choose **Open with Live Server**.

## Files
- `index.html` — complete page structure
- `style.css` — responsive styling and animations
- `script.js` — menu, modal, appointment form, toast notifications, search demo, scroll effects
- `assets/healthcare-hero.png` — generated healthcare visual

## Note
This is a frontend portfolio project. Login, appointment submission, search, and department selection are demo interactions. No real patient data is transmitted or stored.
